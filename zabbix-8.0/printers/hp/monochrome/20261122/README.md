# HP Monochrome Laser Printer by SNMP for Zabbix 8.0

Universal SNMP template for HP monochrome laser printers monitored by Zabbix 8.0.

## Highlights

- Standard SNMP system information
- ICMP availability and response time
- Printer uptime
- Total printed-page counter
- Dashboard-friendly printed-page value with thousands separated by spaces
- Printer-MIB low-level discovery (LLD) of consumables
- Automatically discovers only consumables actually exposed by the printer
- Remaining consumable percentage calculated from Printer-MIB current/max values
- Warning and High triggers for low consumables
- Toner triggers tagged `component=toner` for use in central dashboards
- Host dashboard included

## Tested device

Development and initial validation were performed with an HP LaserJet Pro 4002dn exposing a black cartridge through Printer-MIB.

The template intentionally does not create fixed Cyan/Magenta/Yellow/Drum items. If a monochrome HP model exposes an additional drum or maintenance consumable through Printer-MIB, LLD can discover it automatically.

## Requirements

- Zabbix 8.0
- SNMP enabled on the printer
- SNMP interface configured on the Zabbix host
- ICMP permitted if availability/response-time monitoring is desired
- Printer-MIB supplies table exposed by the device

Use a dedicated read-only SNMP community and restrict access to the Zabbix server/proxy where possible. Do not publish production communities or internal addressing in GitHub issues.

## Import

1. Open `Data collection > Templates > Import`.
2. Import `templates/template_hp_monochrome_laser_printer_snmp.yaml`.
3. For first installation enable **Create new** and **Update existing**.
4. Keep **Delete missing** disabled for initial import.
5. Link `HP Monochrome Laser Printer by SNMP` to the printer host.
6. Configure the host SNMP interface.
7. Run `Printer supplies discovery > Execute now`.
8. Check `Monitoring > Latest data` and the host dashboard.

## Consumables discovery

LLD uses Printer-MIB supply descriptions under:

```text
1.3.6.1.2.1.43.11.1.1.6
```

For each discovered supply it creates:

- Maximum capacity
- Current level
- Remaining percentage
- Remaining-percentage graph
- Warning trigger below the configured warning threshold
- High trigger below the configured critical threshold

Default macros:

| Macro | Default | Purpose |
|---|---:|---|
| `{$PRINTER.SUPPLY.NAME.MATCHES}` | `.+` | Discover every non-empty supply description |
| `{$PRINTER.SUPPLY.WARN}` | `20` | Warning below 20% |
| `{$PRINTER.SUPPLY.CRIT}` | `10` | High below 10% |

Both supply trigger prototypes are tagged:

```text
component=toner
```

This allows a central Zabbix Problems widget to filter printer consumable alerts by `component equals toner`.

## Dashboard

Included dashboard: `HP Monochrome Laser Printer overview`.

It displays:

- ICMP availability
- Ping response time
- System name
- Uptime
- Exact printed-page count
- One consumable Remaining % graph slot
- Ping response-time graph
- Printed pages graph
- Printer problems

The printed-page widget uses a dependent text item to render values such as `10 328`, while the original numeric page counter remains available for history and graphs.

The consumable graph-prototype widget is deliberately configured as a compact 1 x 1 grid for typical monochrome printers with one cartridge, avoiding empty dashboard graph cells.

## Central toner dashboard

Filter a Problems widget using:

```text
Tag name: component
Operator: Equals
Value: toner
```

All toner/consumable warning and high trigger prototypes generated by this template carry that tag.

## Troubleshooting

### `No Such Instance currently exists at this OID`

Do not add fixed toner/drum OIDs for a different printer model. Verify the printer's actual supplies table:

```bash
snmpwalk -v2c -c COMMUNITY PRINTER_IP 1.3.6.1.2.1.43.11.1.1.6
snmpwalk -v2c -c COMMUNITY PRINTER_IP 1.3.6.1.2.1.43.11.1.1.8
snmpwalk -v2c -c COMMUNITY PRINTER_IP 1.3.6.1.2.1.43.11.1.1.9
```

The template is designed to discover the indexes returned by the printer instead of assuming fixed supply indexes.

### No supplies are discovered

- confirm SNMP access;
- inspect the Printer-MIB description walk;
- run the LLD rule manually;
- verify `{$PRINTER.SUPPLY.NAME.MATCHES}` is not excluding the device's supply description.

### Page count is abbreviated in a graph

The numeric graph may use Zabbix automatic unit scaling. The top dashboard tile intentionally uses the separate formatted dependent item for an exact human-readable counter.
