# Changelog

## v1.0.0 - 2026-11-20

- Initial public release for Zabbix 8.0.
- Universal dashboard-free Core template.
- Automatic physical-disk SNMP low-level discovery.
- Per-disk model, state, health, temperature, bad-sector and identify-failure monitoring.
- Dashboard variants for 2, 4 and 8 physical disks.
- Consistent Item value typography, including decimal and unit sizing.
- Conditional dashboard coloring for supported status/capacity/temperature widgets.
- Fan status, uptime, ICMP availability and ping-response monitoring.
- Ping response, system temperature, volume capacity and dynamic disk-temperature graphs.
